# Example Project

Replace this file with one markdown file per project you want the bot to cite
in cover letters and application answers. These files are not read by code;
they are context for the agent that tailors your materials, so write them the
way you would explain the project to a recruiter.

A good project write-up covers:

- **What it is** — one or two plain sentences up top.
- **What you built** — the concrete pieces you were responsible for.
- **Stack and scale** — technologies, and any numbers that make it real
  (users, throughput, uptime, revenue).
- **Outcome** — what happened because it existed. Failures are fine too;
  a well-told lesson can carry an interview question.

Optionally add an `INDEX.md` that lists each project with one line on when to
cite it. The agent reads the index first and opens only the write-ups that fit
the job, which keeps tailoring fast and on-topic.
